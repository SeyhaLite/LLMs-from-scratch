# កូដពីឃ្លាំង upstream (Code mirror)

ថតនេះផ្ទុកចម្លងនៃ **ឯកសារកូដ និងទិន្នន័យ** ពីឃ្លាំង
[rasbt/LLMs-from-scratch](https://github.com/rasbt/LLMs-from-scratch)
(អាជ្ញាបណ្ណ Apache-2.0, (c) Sebastian Raschka) ដោយមិនបានកែប្រែតក្កវិទ្យាកូដ។

- រចនាសម្ព័ន្ធថតត្រូវបានរក្សាដូចដើម ដើម្បីឱ្យការ import ធៀបដំណើរការបាន។
- **មិនបានចម្លង**៖ ឯកសារ Markdown (អត្ថបទសៀវភៅ), រូបភាព, និង workflows —
  ព្រោះអត្ថបទសៀវភៅ និងរូបភាពពាក់ព័ន្ធតរូវបានដកចេញពីវិសាលភាពអាជ្ញាបណ្ណ Apache-2.0
  (ជាកម្មសិទ្ធិរបស់ Manning Publications)។
- Notebooks ត្រូវបានផ្តល់ជាកំណែ Khmer companion នៅថត `../ណូតប៊ុក-ខ្មែរ/`
  (កូដដូចដើម ១០០% + comments បកប្រែ + គ្មានអត្ថបទសៀវភៅ)។

## កំណត់ចំណាំអំពីឯកសារ Markdown

គោលការណ៍ដើមគឺ **មិនចម្លងឯកសារ Markdown ពី upstream** ព្រោះអត្ថបទសៀវភៅត្រូវបានដកចេញ
ពីវិសាលភាពអាជ្ញាបណ្ណ។ ទោះជាយ៉ាងណា ឃ្លាំងនេះមានឯកសារ Markdown **ពីរប្រភេទ
ដែលសហគមន៍ខ្មែរសរសេរឡើងវិញដោយខ្លួនឯង** (មិនមែនជាការចម្លងពី upstream ទេ)៖

| ឯកសារ | លក្ខណៈ |
|---|---|
| `chXX/README.md` (ch01–ch07) | សន្ទស្សន៍ថតជាខ្មែរ — បញ្ជីថត និងតំណភ្ជាប់ (ព័ត៌មានពិត)។ ថតដែលមិនបានចម្លងមកទីនេះ ត្រូវបានភ្ជាប់ទៅ upstream វិញ |
| `ch01/reading-recommendations.md` | កំណែសម្រួលខ្មែរនៃណែនាំការអានរបស់អ្នកនិពន្ធ — សរសេរឡើងវិញដោយសហគមន៍ គ្របដណ្តប់គ្រប់ជំហាន ព្រមទាំងការកត់ត្រាកម្មសិទ្ធិ និងតំណទៅអត្ថបទដើម |

ជំពូក ១ គ្មានកូដសោះនៅ upstream (មានតែឯកសារ Markdown) ដូច្នេះថត `ch01/` នៅទីនេះ
ផ្ទុកតែឯកសារណែនាំជាខ្មែរប៉ុណ្ណោះ។

**នៅតែមិនបានចម្លង៖** អត្ថបទសៀវភៅ, រូបភាពរបស់សៀវភៅ, និង GitHub workflows។
