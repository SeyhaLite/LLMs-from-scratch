សម្ភារៈបន្ថែម (Bonus Material)

Note

ប្រភព៖ ផ្នែក Bonus Material នៃ README.md របស់ upstream។ ថតទាំងនេះជាសម្ភារៈស្រេចចិត្ត (optional) សម្រាប់អ្នកអានដែលចាប់អារម្មណ៍។ ចំណងជើងទាំងអស់ត្រូវបានបកប្រែជាភាសាខ្មែរ ដោយរក្សាពាក្យបច្ចេកទេសអង់គ្លេសដើម។ រូបភាពក្នុងទំព័រនេះជា ដ្យាក្រាមដើមរបស់សហគមន៍ខ្មែរ — រូបភាពរបស់សៀវភៅ (Manning) មិនត្រូវបានចម្លងមកទីនេះទេ តាមគោលការណ៍ក្នុង LICENSE។

ការដំឡើង (Setup)

  • គន្លឹះការដំឡើង Python (Python Setup Tips)

  • ការដំឡើង Package និងបណ្ណាល័យ Python ដែលប្រើក្នុងសៀវភៅនេះ

  • មគ្គុទ្ទេសក៍ដំឡើងបរិស្ថាន Docker

ជំពូក ២ — ការធ្វើការជាមួយទិន្នន័យអត្ថបទ (Working With Text Data)

  • សាងសង់ Byte Pair Encoding (BPE) Tokenizer ពីមូលដ្ឋាន

  • ប្រៀបធៀបការអនុវត្ត Byte Pair Encoding (BPE) ផ្សេងៗ

  • ស្វែងយល់ភាពខុសគ្នារវាង Embedding Layer និង Linear Layer

  • ការយល់ដឹងអំពី Dataloader ដោយប្រើលេខសាមញ្ញ

  • សាងសង់ BPE ពីមូលដ្ឋាន

  • កំណែ SimpleTokenizerV3

ជំពូក ៣ — សរសេរកូដយន្តការ Attention (Coding Attention Mechanisms)

  • ប្រៀបធៀបការអនុវត្ត Multi-Head Attention ដែលមានប្រសិទ្ធភាព

  • ស្វែងយល់ពី PyTorch Buffers

ជំពូក ៤ — អនុវត្តម៉ូដែល GPT ពីមូលដ្ឋាន (Implementing a GPT Model From Scratch)

  • ការវិភាគ FLOPs

  • KV Cache

  • ជម្រើសជំនួស Attention (Attention Alternatives)៖

    • Grouped-Query Attention (GQA)

    • Multi-Head Latent Attention (MLA)

    • Sliding Window Attention (SWA)

    • Gated DeltaNet

    • DeepSeek Sparse Attention (DSA)

    • ការចែករំលែក KV រវាងស្រទាប់ (Cross-Layer KV Sharing)

  • Mixture-of-Experts (MoE)

ជំពូក ៥ — Pretraining លើទិន្នន័យគ្មានស្លាក (Pretraining on Unlabeled Data)

  • វិធីសាស្ត្រផ្ទុក Weight ជំនួស

  • Pretraining ម៉ូដែល GPT លើ Dataset របស់ Project Gutenberg

  • ការបន្ថែមមុខងារកម្រិតខ្ពស់ទៅក្នុង Training Loop

  • ភាពខុសគ្នារវាងឧបករណ៍ CPU និង MPS

  • ការកែលម្អ Hyperparameter សម្រាប់ Pretraining

  • ការសាងសង់ User Interface ដើម្បីប្រើប្រាស់ LLM ដែល Pretrain រួច

  • ការបំលែង GPT ទៅ Llama

  • ការផ្ទុក Model Weight ដោយសន្សំសំចៃអង្គចងចាំ

  • ការពង្រីក Tiktoken BPE Tokenizer ដោយ Token ថ្មី

  • គន្លឹះ PyTorch Performance ដើម្បីបណ្តុះបណ្តាល LLM លឿនជាង

  • ស្ថាបត្យកម្ម LLM (LLM Architectures)៖

    • សាងសង់ Llama 3.2 ពីមូលដ្ឋាន

    • សាងសង់ Qwen3 Dense និង Mixture-of-Experts (MoE) ពីមូលដ្ឋាន

    • សាងសង់ Gemma 3 ពីមូលដ្ឋាន

    • សាងសង់ Olmo 3 ពីមូលដ្ឋាន

    • សាងសង់ Tiny Aya ពីមូលដ្ឋាន

    • សាងសង់ Qwen3.5 ពីមូលដ្ឋាន

    • សាងសង់ Gemma 4 E2B និង E4B ពីមូលដ្ឋាន

  • ជំពូក ៥ ជាមួយ LLM ផ្សេងជាការជំនួសដោយផ្ទាល់ (ឧទាហរណ៍ Llama 3, Qwen 3)

ជំពូក ៦ — Finetuning សម្រាប់ការចាត់ថ្នាក់ (Finetuning for Classification)

  • ការពិសោធន៍បន្ថែម៖ Finetuning ស្រទាប់ផ្សេងៗ និងប្រើម៉ូដែលធំជាង

  • Finetuning ម៉ូដែលផ្សេងៗលើ Dataset IMDb Movie Review ៥០ ពាន់

  • ការសាងសង់ User Interface ដើម្បីប្រើប្រាស់ Spam Classifier ដែលផ្អែកលើ GPT

ជំពូក ៧ — Finetuning ដើម្បីធ្វើតាមការណែនាំ (Finetuning to Follow Instructions)

  • ឧបករណ៍ជំនួយ Dataset សម្រាប់រក Near Duplicate និងបង្កើតធាតុ Passive Voice

  • ការវាយតម្លៃចម្លើយ Instruction ដោយប្រើ OpenAI API និង Ollama

  • ការបង្កើត Dataset សម្រាប់ Instruction Finetuning

  • ការកែលម្អ Dataset សម្រាប់ Instruction Finetuning

  • ការបង្កើត Preference Dataset ដោយប្រើ Llama 3.1 70B និង Ollama

  • Direct Preference Optimization (DPO) សម្រាប់ការតម្រឹម LLM

  • ការសាងសង់ User Interface ដើម្បីប្រើប្រាស់ម៉ូដែល GPT ដែល Instruction-Finetune រួច
