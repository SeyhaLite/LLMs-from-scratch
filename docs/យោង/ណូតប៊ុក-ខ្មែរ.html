របៀបដំណើរការ

  1. clone ឃ្លាំង upstream និងឃ្លាំងឯកសារខ្មែរនេះ។

  2. notebook នីមួយៗមាន connection cell ដំបូងដែលចង្អុល sys.path និងថតធ្វើការ ទៅកាន់ថត កូដ/ ក្នុងឃ្លាំងនេះស្វ័យប្រវត្តិ — ដូច្នេះវាដំណើរការភ្ជាប់ដូច notebook ដើម (គ្រាន់តែបើកវាពីក្នុងឃ្លាំងដែលបាន clone មក ហើយដំណើរការ cells តាមលំដាប់)។ ជាជម្រើស អ្នកអាចចម្លង Notebook ខ្មែរដែលអ្នកចង់ប្រើ ទៅដាក់ក្នុងថតជំពូកដែលត្រូវគ្នានៅក្នុងឃ្លាំង upstream (ឧ. ch02/01_main-chapter-code/) ដើម្បីឲ្យកូដរកឃើញឯកសារជំនួយ (previous_chapters.py, gpt_download.py, ឯកសារទិន្នន័យ ជាដើម)។

  3. ដំឡើង dependencies៖ pip install -r requirements.txt ពីថត root របស់ upstream (មើលទំព័រ ការដំឡើងបរិស្ថាន)។

  4. បើក notebook ក្នុង JupyterLab ឬ VSCode ហើយដំណើរការ cells តាមលំដាប់។ លើ Google Colab សូម upload ទាំង notebook និងឯកសារជំនួយដែលត្រូវការ។

Warning

កូដខ្លះត្រូវការការទាញយក weights pretrained (ឧ. ជំពូក ៥–៧ និងភាគបន្ថែម E) ដែលត្រូវការអ៊ីនធឺណិត និងទំហំថាសគ្រប់គ្រាន់។

សម្ភារៈបន្ថែមទាំងអស់ (49 notebooks)

ក្រៅពី notebooks ស្នូល ១៩ ខាងលើ ឃ្លាំងនេះមាន companion notebooks ខ្មែរសម្រាប់ notebooks ទាំងអស់ ៦៨ របស់ upstream (កូដដូចដើម ១០០% + comments បកប្រែ គ្មានអត្ថបទសៀវភៅ) នៅក្នុងថតរង ណូតប៊ុក-ខ្មែរ/បន្ថែម/ រៀបតាមជំពូក៖ មើលថតបន្ថែម។

ឯកសារកូដ និងទិន្នន័យទាំងអស់របស់ upstream (.py, .txt, .json ជាដើម) ក៏ត្រូវបានផ្ទុកក្នុងឃ្លាំងនេះដែរ នៅថត កូដ/ ដោយរក្សារចនាសម្ព័ន្ធដូចដើម ដើម្បីឱ្យកូដដំណើរការបាន។
