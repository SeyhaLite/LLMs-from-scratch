ការមើលឯកសារ Markdown

ឯកសារ README.md ជាឯកសារ Markdown (.md)។ បើអ្នកមើលវានៅលើកុំព្យូទ័រផ្ទាល់ខ្លួន គួរប្រើកម្មវិធីកែសម្រួល ឬមើលជាមុន Markdown សម្រាប់ការបង្ហាញត្រឹមត្រូវ — Ghostwriter គឺជាជម្រើសឥតគិតថ្លៃដ៏ល្អមួយ។ ជាជម្រើសទីពីរ មើលឯកសារទាំងនេះនៅលើ GitHub ផ្ទាល់ ដែល render Markdown ដោយស្វ័យប្រវត្តិ។

ការធ្វើតេស្តកូដ (CI)

ឃ្លាំង upstream មាន GitHub Actions workflow សម្រាប់ធ្វើតេស្តកូដលើប្រព័ន្ធទាំងបី៖ Linux, Windows និង macOS។ នេះមានន័យថាកូដត្រូវបានផ្ទៀងផ្ទាត់ជាប្រចាំលើប្រព័ន្ធប្រតិបត្តិការទាំងអស់។
