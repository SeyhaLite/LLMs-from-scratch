LLMs ពីមូលដ្ឋាន — ឯកសារសហគមន៍ភាសាខ្មែរ

នេះជាគេហទំព័រឯកសារសហគមន៍ (community documentation) ភាសាខ្មែរ ដែលសង្ខេបព័ត៌មានពិតៗ ពីឃ្លាំងកូដផ្លូវការ rasbt/LLMs-from-scratch — ឃ្លាំងកូដផ្លូវការសម្រាប់សៀវភៅ Build a Large Language Model (From Scratch) របស់ Sebastian Raschka (Manning)។ ឃ្លាំងកូដនេះណែនាំការអភិវឌ្ឍ (develop) ការបណ្តុះបណ្តាលមុន (pretrain) និងការកែសម្រួល (finetune) ម៉ូដែលភាសាធំស្រដៀង GPT ដោយប្រើ PyTorch ពីមូលដ្ឋាន ដោយមិនប្រើបណ្ណាល័យ LLM ខាងក្រៅ។ គ្រប់ជំពូក និងភាគបន្ថែមមាន companion notebook ជាភាសាខ្មែរ (កូដដូច upstream ១០០% ព្រមទាំងការពន្យល់ និង comments ជាខ្មែរ) — សូមមើល Notebooks ភាសាខ្មែរ (Companion Notebooks)។

Note

ឯកសារនេះជាការបកប្រែ/សង្ខេបរបស់សហគមន៍ — មិនមែនជាឯកសារផ្លូវការ របស់អ្នកនិពន្ធ ឬក្រុមហ៊ុន Manning ទេ។ ប្រភពចម្បងដែលត្រូវយកជាគោលគឺឃ្លាំងកូដ upstream ភាសាអង់គ្លេស។ អត្ថបទ និងរូបភាពក្នុងសៀវភៅជាកម្មសិទ្ធិរបស់ Manning — គេហទំព័រនេះមិនចម្លងវាទេ។
