ឯកសារណែនាំរបស់ជំពូក (កំណែខ្មែរ)

reading-recommendations.md

ណែនាំអំពីរបៀបអានសៀវភៅបច្ចេកទេសឱ្យទទួលបានផលច្រើនបំផុត (កំណែសម្រួលខ្មែរ)

មេរៀនពេញលេញ (សិក្សាងាយ)

ការពន្យល់ខាងក្រោមជា អត្ថបទដើមរបស់សហគមន៍ខ្មែរ (មិនមែនជាការចម្លងអត្ថបទសៀវភៅទេ) សរសេរឡើងដើម្បីឱ្យអ្នកសិក្សាយល់គោលគំនិតទាំងអស់នៃជំពូក ១ មុនពេលចូលដល់ការសរសេរកូដ។

១. LLM គឺជាអ្វី?

Large Language Model (LLM) គឺជាបណ្តាញសរសៃប្រសាទសិប្បនិម្មិតដែលត្រូវបានបណ្តុះបណ្តាល លើអត្ថបទបរិមាណច្រើនមហាសាល ដើម្បីរៀន ព្យាករណ៍ token បន្ទាប់។

ចំណុចសំខាន់ដែលត្រូវចាំ៖

  • ម៉ូដែលមិនត្រូវបានកំណត់ច្បាប់វេយយាករណ៍ ឬវចនានុក្រមដោយដៃទេ។

  • ចំណេះដឹងភាសា ការតភ្ជាប់ន័យ និងសមត្ថភាពបង្កើតអត្ថបទ កើតចេញពីស្ថិតិ នៃការបណ្តុះបណ្តាល។

  • ពាក្យ "ធំ" (Large) សំដៅលើចំនួន parameter — ធម្មតាចាប់ពីរយលាន ដល់រាប់ពាន់លាន ឬច្រើនជាងនេះ។

២. ដំណើរវិវត្ត ពី deep learning ទៅ LLM

ដំណាក់កាល

ខ្លឹមសារ

Deep learning

បណ្តាញសរសៃប្រសាទច្រើនស្រទាប់ រៀនលក្ខណៈ (features) ដោយស្វ័យប្រវត្តិពីទិន្នន័យឆៅ

Word embedding

តំណាងពាក្យជាវ៉ិចទ័រលេខ ដែលធ្វើឱ្យពាក្យមានន័យជិតគ្នាស្ថិតនៅជិតគ្នាក្នុងលំហ

Transformer

ស្ថាបត្យកម្មដែលប្រើ attention ជំនួស RNN អនុញ្ញាតឱ្យគណនាស្រប (parallel) បាន

LLM

Transformer ដែលពង្រីកទំហំ ហើយបណ្តុះបណ្តាលលើអត្ថបទច្រើន រហូតដល់មានសមត្ថភាពភាសាទូទៅ

៣. Pretraining និង Finetuning

ការបង្កើត LLM មានពីរដំណាក់កាលសំខាន់៖

ដំណាក់កាលទី ១ — Pretraining

  • ប្រើទិន្នន័យ គ្មានស្លាក (unlabeled) ដូចជាអត្ថបទពីគេហទំព័រ សៀវភៅ និងកូដ។

  • កិច្ចការ៖ ព្យាករណ៍ token បន្ទាប់ (next-token prediction)។

  • លទ្ធផល៖ base model ដែលចេះភាសា ប៉ុន្តែមិនទាន់ចេះ "សន្ទនា"។

  • ចំណាយថ្លៃខ្លាំង — ត្រូវការ GPU និងពេលវេលាច្រើន។

ដំណាក់កាលទី ២ — Finetuning

  • ប្រើទិន្នន័យ មានស្លាក ឬមានទម្រង់ជាក់លាក់ តិចជាង pretraining ច្រើន។

  • ប្រភេទសំខាន់ៗ៖

    • Classification finetuning — បន្ថែមស្រទាប់ចំណាត់ថ្នាក់ ដើម្បីវិនិច្ឆ័យអត្ថបទ (ជំពូក ៦)។

    • Instruction finetuning — បង្រៀនឱ្យឆ្លើយតបតាមការណែនាំក្នុងទម្រង់សន្ទនា (ជំពូក ៧)។

៤. ត្រកូល GPT (decoder-only)

Transformer ដើមមានពីរផ្នែក៖ encoder និង decoder។ ត្រកូល GPT ប្រើតែផ្នែក decoder។

លក្ខណៈសំខាន់៖

  • បង្កើតអត្ថបទ ម្តងមួយ token (autoregressive) — token ដែលបង្កើតហើយក្លាយជា input សម្រាប់ token បន្ទាប់។

  • ប្រើ causal attention — token នីមួយៗអាចមើលឃើញតែ token នៅពីមុខវាប៉ុណ្ណោះ។

  • ឧទាហរណ៍ម៉ូដែលក្នុងត្រកូលនេះ៖ GPT-2, GPT-3, GPT-4, Llama, Qwen, Gemma។

៥. Attention គឺជាអ្វី? (គំនិតដំបូង)

Attention គឺជាយន្តការដែលអនុញ្ញាតឱ្យម៉ូដែល "ផ្តោតអារម្មណ៍" លើផ្នែកដែលពាក់ព័ន្ធនៃ input នៅពេលដំណើរការ token នីមួយៗ។

គំនិតសាមញ្ញ៖ ពេលអានឃ្លា "ខ្ញុំទិញកុំព្យូទ័រថ្មី ព្រោះវាលឿនណាស់" យើងដឹងភ្លាមថាពាក្យ "វា" សំដៅលើ "កុំព្យូទ័រ" មិនមែន "ខ្ញុំ"។ Attention ធ្វើការងារដូចគ្នានេះតាមរយៈ ទម្ងន់លេខ ដែលគណនាថាតើ token ណាសំខាន់សម្រាប់ token បច្ចុប្បន្ន។ ជំពូក ៣ នឹងសរសេរកូដវាពេញលេញ។

៦. ហេតុអ្វីត្រូវសាងសង់ពីមូលដ្ឋាន?

អ្នកអាចហៅបណ្ណាល័យ transformers ឬ API ដោយប្រើតែពីរបីបន្ទាត់កូដ។ ប៉ុន្តែការសរសេរវាដោយខ្លួនឯងផ្តល់អត្ថប្រយោជន៍ខុសគ្នាទាំងស្រុង៖

  • យល់ដឹងជ្រៅ — អ្នកដឹងថាអ្វីកើតឡើងខាងក្នុង មិនមែនគ្រាន់តែដឹងថាវាដំណើរការទេ។

  • debug បាន — ពេល loss មិនចុះ អ្នកអាចរកឃើញថាវាជាបញ្ហា tokenizer, learning rate ឬ attention mask។

  • កែប្រែបាន — អាចបង្កើតស្ថាបត្យកម្មថ្មី ឬសាកល្បងគំនិតដែលបណ្ណាល័យមិនទាន់គាំទ្រ។

  • វាយតម្លៃបាន — អាចប្រៀបធៀបម៉ូដែលដោយយល់ពីមូលហេតុពិតប្រាកដ។

៧. វដ្តអភិវឌ្ឍន៍ LLM ទាំងមូល

៨. វាក្យសព្ទគន្លឹះនៃជំពូកនេះ

token

ឯកតាតូចបំផុតនៃអត្ថបទដែលម៉ូដែលដំណើរការបាន (ពាក្យ កំណាត់ពាក្យ ឬអក្សរ)។

parameter

តម្លៃលេខដែលម៉ូដែលរៀនកែប្រែអំឡុងពេលបណ្តុះបណ្តាល។

pretraining

ការបណ្តុះបណ្តាលលើទិន្នន័យគ្មានស្លាក ដើម្បីរៀនភាសាទូទៅ។

finetuning

ការបណ្តុះបណ្តាលបន្ថែមលើទិន្នន័យជាក់លាក់ ដើម្បីកែសម្រួលម៉ូដែលសម្រាប់កិច្ចការមួយ។

autoregressive

ការបង្កើតលទ្ធផលម្តងមួយឯកតា ដោយប្រើលទ្ធផលមុនជា input។

causal attention

attention ដែលរារាំងមិនឱ្យ token មើលឃើញ token នៅអនាគត។

base model

ម៉ូដែលដែលឆ្លងកាត់តែ pretraining មិនទាន់ finetune សម្រាប់កិច្ចការជាក់លាក់។

Important
