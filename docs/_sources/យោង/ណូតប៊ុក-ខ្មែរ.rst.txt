Notebooks ភាសាខ្មែរ (Companion Notebooks)
===========================================

.. note::

   ឃ្លាំងនេះផ្តល់ **companion notebooks** ជាភាសាខ្មែរ៖ កូដទាំងអស់គឺ **ដូចគ្នា ១០០%**
   ទៅនឹង notebooks ផ្លូវការរបស់ upstream (អាជ្ញាបណ្ណ Apache-2.0) ហើយការពន្យល់រវាង
   កូដនីមួយៗគឺជា **អត្ថបទខ្មែរដើម** របស់សហគមន៍ — មិនមែនជាការបកប្រែអត្ថបទសៀវភៅទេ
   (អត្ថបទសៀវភៅជាកម្មសិទ្ធិ Manning និងស្ថិតក្រៅវិសាលភាពអាជ្ញាបណ្ណបើកចំហ)។

របៀបដំណើរការ
----------------

1. clone ឃ្លាំង upstream និងឃ្លាំងឯកសារខ្មែរនេះ។
2. notebook នីមួយៗមាន **connection cell** ដំបូងដែលចង្អុល ``sys.path`` និងថតធ្វើការ
   ទៅកាន់ថត ``កូដ/`` ក្នុងឃ្លាំងនេះស្វ័យប្រវត្តិ — ដូច្នេះវាដំណើរការភ្ជាប់ដូច notebook ដើម
   (គ្រាន់តែបើកវាពីក្នុងឃ្លាំងដែលបាន clone មក ហើយដំណើរការ cells តាមលំដាប់)។ ជាជម្រើស អ្នកក៏អាច
   ជាជម្រើស អ្នកអាចចម្លង Notebook ខ្មែរដែលអ្នកចង់ប្រើ ទៅដាក់ក្នុងថតជំពូកដែលត្រូវគ្នានៅក្នុងឃ្លាំង upstream
   (ឧ. ``ch02/01_main-chapter-code/``) ដើម្បីឲ្យកូដរកឃើញឯកសារជំនួយ
   (``previous_chapters.py``, ``gpt_download.py``, ឯកសារទិន្នន័យ ជាដើម)។
3. ដំឡើង dependencies៖ ``pip install -r requirements.txt`` ពីថត root របស់ upstream
   (មើលទំព័រ :doc:`../ការចាប់ផ្តើម/ការដំឡើងបរិស្ថាន`)។
4. បើក notebook ក្នុង JupyterLab ឬ VSCode ហើយដំណើរការ cells តាមលំដាប់។
   លើ Google Colab សូម upload ទាំង notebook និងឯកសារជំនួយដែលត្រូវការ។

.. warning::

   កូដខ្លះត្រូវការការទាញយក weights pretrained (ឧ. ជំពូក ៥–៧ និងភាគបន្ថែម E)
   ដែលត្រូវការអ៊ីនធឺណិត និងទំហំថាសគ្រប់គ្រាន់។
